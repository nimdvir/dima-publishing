# Chapter 8: Midterm Review — Concepts

*Putting the First Half of the Course Together*

Chapter 8 is the synthesis point for the first half of BITM330. It reviews how data, tables, keys, relationships, SQL, and normalization fit together as one connected system, then gives you the full instructions for the midterm test (query an existing quiz database in Microsoft Access) and the midterm project (build a grading database from scratch). Together, these two assessments confirm you can move from data to tables to relationships to queries to decisions.
