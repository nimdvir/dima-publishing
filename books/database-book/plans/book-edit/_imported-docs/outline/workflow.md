## The Optimal Workflow for Your Book

### Phase 1 — Chapter-by-Chapter Rewrite (Primary Phase)

For **each chapter**:

1. Rewrite with **Opus 4.6**
2. Ensure:
   * Clear learning arc
   * Friendly, flowing tone
   * Correct Bloom level
   * Grading DB + Vet DB used appropriately
3. Lock the chapter

✅ Outcome: *Publication-quality individual chapter*

---

### Phase 2 — Light Integration Pass (Every 3–4 Chapters)

After every 3–4 chapters:

* Add:
  * “As introduced in Chapter X…”
  * “We will build on this in Chapter Y…”
* Align terminology
* Normalize examples

This prevents drift **without overfitting too early**.

---

### Phase 3 — Full Integration Sweep (Near the End)

Once *all chapters are stable*:

* One final pass to:
  * Tighten cross-chapter language
  * Smooth transitions between parts
  * Align conclusions + intro
  * Standardize metaphors and recurring phrases

This is where the book starts to feel *designed*, not compiled.
