**Q1. Select ALL that apply: An organization is designing row-level security for a multi-tenant application. Which principles should guide the design?**

*Short description: Tests your ability to identify correct security architecture principles for multi-tenant data access.*

A. Each authenticated user should only access rows belonging to their own organization or account ← ✓ CORRECT
*Feedback: Correct — this is the core principle of multi-tenant RLS.*

B. A service account with broad access should be embedded in public browser code for convenience
*Feedback: Incorrect — broad service credentials must never be exposed in public code.*

C. AI retrieval systems should respect the same row-level permissions as direct user access ← ✓ CORRECT
*Feedback: Correct — AI does not create an exception to privacy rules.*

D. An instructor role should have different row access than a student role ← ✓ CORRECT
*Feedback: Correct — role-based access is a fundamental RLS pattern.*

E. Row-level policies act like automatic WHERE conditions added to relevant queries ← ✓ CORRECT
*Feedback: Correct — this is the conceptual model for how RLS policies work.*

**Hint:** Think about least privilege — who needs access to what, and how should that be enforced?

**Explanation:** Row-level security applies authorization at the row level. Policies act as automatic WHERE clauses. Different roles need different access. AI retrieval must respect the same permissions as direct user access. Service credentials with broad access must never be exposed in public code.

**Q2. Select ALL that apply: A hospital wants to use AI to answer staff questions using approved policy documents. Which architecture decisions support responsible implementation?**

*Short description: Tests your ability to evaluate AI-readiness practices for governed document retrieval.*

A. Store policy documents with version numbers, effective dates, and approval status ← ✓ CORRECT
*Feedback: Correct — versioned, dated, and approved documents are essential for AI readiness.*

B. Create retrieval views that expose only approved and current document versions ← ✓ CORRECT
*Feedback: Correct — governed views prevent stale or draft content from reaching the model.*

C. Apply row-level or document-level access controls before retrieval ← ✓ CORRECT
*Feedback: Correct — authorization must occur before data enters the model context.*

D. Allow the AI model to access all documents in the network without restriction
*Feedback: Incorrect — unrestricted access violates privacy and governance principles.*

E. Include source citations and effective dates in generated answers ← ✓ CORRECT
*Feedback: Correct — citations allow users to verify the source and check currency.*

**Hint:** Authorization must happen before data reaches the model. What metadata and controls make retrieval trustworthy?

**Explanation:** AI-ready document systems require version control, approval status, effective dates, governed retrieval views, pre-retrieval access controls, and citations. Unrestricted access is a dangerous anti-pattern — AI does not create an exception to privacy rules.

## Multiple-Choice Questions

**Q3. A university runs a registration system handling thousands of enrollments per hour and also needs to analyze five years of grade data for student success predictors. Which architectural approach is most appropriate?**

*Short description: Tests ability to apply workload separation principles to a realistic institutional scenario.*

A. Run both workloads on the same operational database
B. Maintain the registration system on an OLTP-optimized database and periodically load cleaned grade history into a separate analytical store
C. Move all data into a data lake and run analytical queries directly against registration tables
D. Replace the registration system with a spreadsheet

**Correct Answer:** B
**Explanation:** OLTP (transaction processing) and OLAP (analytical processing) have different design priorities. Running complex historical queries against the live registration system would slow down student enrollments. Separating the workloads preserves transaction speed while enabling historical analysis.

**Points:** 1 | **Difficulty:** 4/5 | **ID:** BITM330-CH14-Q03 | **Bloom:** Apply

**Q4. An organization built a data warehouse three years ago. Two departments now report different values for "monthly revenue" even though both use the same warehouse. What is the most likely root cause?**

*Short description: Tests ability to diagnose governance failures in analytical infrastructure.*

A. The warehouse hardware is faulty
B. The organization lacks a single governed definition of the metric, and departments apply different filters or inclusion rules
C. SQL cannot calculate revenue correctly
D. One department is using OLTP instead of OLAP

**Correct Answer:** B
**Explanation:** When different departments produce conflicting numbers from the same data source, the root cause is almost always a governance gap — no single agreed-upon definition of the metric. Without governed definitions, different teams apply different filters, date ranges, or inclusion rules, producing different results.

**Q5. A team stores product catalog data in flexible document columns. Over time, different team members use different field names for the same concept. What is the fundamental problem?**

*Short description: Tests ability to identify the governance risk of flexible data models.*

A. Document columns are incompatible with modern databases
B. Flexibility without governance leads to inconsistency — the documents lack enforced naming conventions and validation
C. The data should have been stored in a graph database
D. Document columns cannot store numeric values

**Correct Answer:** B
**Explanation:** Flexible document storage offers adaptability, but flexibility without governance creates chaos. Without naming conventions, validation rules, and documentation, the same concept gets recorded under different field names, making queries unreliable. The chapter warns: flexibility does not mean absence of design.

**Q6. A bank's distributed transaction system experiences a network partition between two data centers. Customer account balances are at stake. Which CAP trade-off decision is most defensible?**

*Short description: Tests ability to apply the CAP theorem to a high-stakes financial scenario.*

A. Prioritize availability — allow both centers to process withdrawals independently
B. Prioritize consistency — suspend transactions at one center until communication is restored
C. Shut down all banking operations globally
D. Ignore the partition and hope it resolves itself

**Correct Answer:** B
**Explanation:** For financial transactions involving account balances, consistency is more important than availability. Allowing independent withdrawals during a partition could overdraw accounts. The CAP theorem states you cannot have both perfect consistency and complete availability during a partition — you must choose. For banking, correctness takes priority.

**Points:** 1 | **Difficulty:** 5/5 | **ID:** BITM330-CH14-Q06 | **Bloom:** Evaluate

**Q7. A company is building a customer-facing AI assistant. The proposed architecture sends the entire customer database to the LLM with every request, relying on a prompt instruction to limit access. What is the most serious flaw?**

*Short description: Tests ability to recognize that prompts are not security boundaries.*

A. The prompt is too long
B. Using a prompt instruction as a security boundary is not reliable — authorization must be enforced through database controls before data reaches the model
C. LLMs cannot process database records
D. The database should use NoSQL

**Correct Answer:** B
**Explanation:** A prompt instruction asking the model to restrict information is not a security boundary. Authorization must be enforced at the database level before data enters the model context. Sending all data and hoping the model filters it correctly is a dangerous design that violates the principle of least privilege.

**Points:** 1 | **Difficulty:** 5/5 | **ID:** BITM330-CH14-Q07 | **Bloom:** Evaluate

**Q8. A startup stores all data in flexible document columns. At 50 million records, queries searching inside documents are slow. What is the most appropriate response?**

*Short description: Tests ability to evaluate the trade-off between flexibility and performance at scale.*

A. Continue — performance will improve automatically
B. Evaluate which fields are consistently queried and consider extracting them into indexed relational columns while keeping variable attributes in documents
C. Delete half the data
D. Replace with a key-value store

**Correct Answer:** B
**Explanation:** A hybrid approach is often best: keep stable, frequently-queried fields in indexed relational columns, and use document columns for truly variable attributes. This preserves flexibility where needed while gaining relational performance where it matters. The chapter recommends this pattern: a relational core with a flexible edge.

**Points:** 1 | **Difficulty:** 5/5 | **ID:** BITM330-CH14-Q08 | **Bloom:** Evaluate

**Q9. A RAG system retrieves a policy document and generates an answer. The answer is fluent but contradicts the retrieved document. What is the most likely explanation?**

*Short description: Tests ability to diagnose RAG failure — distinguishing retrieval failure from generation failure.*

A. The database connection failed
B. The model generated a plausible continuation not faithful to the evidence — retrieval succeeded but generation failed
C. Vector search cannot retrieve text documents
D. The user asked the wrong question

**Correct Answer:** B
**Explanation:** Retrieval-Augmented Generation can fail at two stages: retrieval (wrong or missing documents) and generation (model ignores or misstates the evidence). When the correct document was retrieved but the answer contradicts it, the failure is in generation — the model produced fluent but unfaithful output.

**Q10. The chapter argues that modern infrastructure does not always require abandoning relational databases. A growing company with operational, analytical, and AI retrieval needs should consider which approach?**

*Short description: Tests ability to evaluate whether relational technology remains appropriate for modern multi-mode workloads.*

A. Replace everything with a vector database
B. A strong relational platform can support all three modes — operational, analytical, and AI retrieval — when the workload and scale are appropriate
C. Relational databases are obsolete for any modern use case
D. Use separate NoSQL systems for each mode with no relational component

**Correct Answer:** B
**Explanation:** The chapter's central thesis is that relational databases remain foundational. Modern platforms support operational tables, analytical queries, document columns, full-text search, and vector similarity — all within one environment. Moving to the cloud or adding AI does not require abandoning relational design; it requires good design that scales.
