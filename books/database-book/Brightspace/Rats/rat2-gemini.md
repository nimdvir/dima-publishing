# Top 10 High-Value Questions for Chapter 2: Foundations of Information Systems

This document curates the 10 most valuable, application and scenario-based questions from the Chapter 2 RAT. They target the Apply, Analyze, and Evaluate Bloom levels to test students on deeper conceptual understanding and practical reasoning.

## Multiple Answer (Select ALL that apply)

**1. A coffee shop owner installs new...**
Select ALL that apply: A coffee shop owner installs new point-of-sale software but does not train staff, update inventory processes, or define data entry standards. Six months later, reports are inconsistent and staff do not trust the numbers. Applying the chapter's concepts, which problems does this scenario illustrate?

[x] A failure of data quality (inconsistent entries)
[x] Neglecting the people and processes components of the five-component framework
[ ] The software is defective and must be replaced
[ ] A strategic alignment failure — the software does not fit the business
[x] Confusing IT (the software) with IS (the full system)

**Explanation:** Installing software without processes, training, and data standards is confusing IT with IS. Missing people and processes components causes system failure. Inconsistent entries are a data quality problem.

**2. According to the chapter's discussion of...**
Select ALL that apply: According to the chapter's discussion of IT governance, which questions fall under governance rather than day-to-day system administration?

[x] How does the organization know whether a system creates value?
[x] Who owns the data?
[x] Who decides which systems are built or purchased?
[x] Who can change records, reports, or system settings?
[ ] What server should host the database?

**Explanation:** Governance asks: Who decides which systems are built or purchased? Who owns the data? Who is responsible for security? How are risks managed? Who can change records, reports, or system settings? How does the organization know whether a system creates value?

**3. A hospital administrator wants to know...**
A hospital administrator wants to know whether a new scheduling system reduced patient wait times. The administrator compares average wait times from the three months before and after the system launched. Which chapter concept does this most directly illustrate?

[ ] The five-component framework
[ ] IT governance
[x] Using a KPI to measure performance improvement
[ ] The DIKW hierarchy

**Explanation:** KPIs translate goals into measurable signals. Comparing before and after using a KPI (average wait time) is exactly how organizations evaluate whether performance improved.

**4. A call center manager sets a...**
A call center manager sets a KPI of "average handling time under three minutes." Staff begin cutting calls short and leaving issues unresolved. Which chapter insight does this scenario illustrate?

[ ] KPIs are always harmful
[x] KPIs shape behavior, and poorly designed KPIs can encourage the wrong behavior
[ ] Call centers should not use any KPIs
[ ] Average handling time is an invalid metric

**Explanation:** When you evaluate a KPI, ask not only what it measures but also what behavior it encourages. A KPI that looks neutral on a dashboard can drive teams toward speed at the cost of quality.

**5. A company installs an expensive analytics...**
A company installs an expensive analytics platform that generates impressive-looking dashboards. However, the underlying data comes from spreadsheets with inconsistent naming and duplicate entries. Using the chapter's concepts, what is the most fundamental problem?

[ ] The company does not have enough KPIs
[ ] The dashboards are poorly designed
[x] The data-to-performance chain is broken at the foundation — poor data quality undermines everything built on it
[ ] The company chose the wrong analytics platform

**Explanation:** The data-to-performance chain starts with data. If data quality is poor, everything downstream is compromised. Inconsistent, duplicate data breaks the foundation, making every report, dashboard, and decision unreliable.

**6. A manager receives a weekly report...**
A manager receives a weekly report showing that Product A sales dropped 15 percent. The report does not include comparison data from prior periods, inventory levels, or promotion history. Applying the chapter's definition of information versus data, what is the problem?

[x] The 15 percent figure is data, not information — it lacks the context needed for interpretation
[ ] The manager should ask for a daily report instead
[ ] Sales reports should never include percentages
[ ] The report contains too much data

**Explanation:** Data needs context. Context tells us what a value represents, where it came from, when it was recorded, and how it should be interpreted. Without context, data is just a recorded trace.

**7. A hospital implements a new patient-records...**
A hospital implements a new patient-records system. The hardware is reliable and the software functions correctly, but doctors resist using it because it adds 12 minutes of data entry per patient visit with no perceived benefit to care quality. Which component(s) of the five-component framework explain the failure?

[ ] Software only
[ ] Data only
[ ] Hardware only
[x] Processes and people

**Explanation:** All five components matter. The process (12 extra minutes of data entry) is poorly designed, and people (doctors) resist because they see no benefit — a process and people failure.

**8. In the chapter, strategic alignment is...**
In the chapter, strategic alignment is defined as the principle that systems should support organizational goals. Which scenario best illustrates a misalignment?

[ ] A delivery company building a route optimization tool
[ ] A hospital implementing a patient safety tracking system
[ ] A university installing a student information system
[x] A cost-focused retailer investing heavily in personalization features that customers never use

**Explanation:** A system can be technically impressive and still fail if it does not fit the organization. A cost-focused retailer investing in unused personalization is a clear misalignment — the system does not support the strategy.

**9. A company's leadership is deciding whether...**
A company's leadership is deciding whether to invest $2 million in a new enterprise resource planning system. Applying BITM thinking, which question is most important to answer first?

[ ] Which vendor has the most advanced features?
[x] What business goals will this system support, and how will we measure whether it creates value?
[ ] How long will installation take?
[ ] What color should the dashboard be?

**Explanation:** BITM asks which technologies an organization should invest in, how risks should be managed, and how technology value should be measured. It starts with business goals and value measurement before vendor evaluation.

**10. An online retailer competes on fast,...**
An online retailer competes on fast, reliable delivery. Its order-management system was designed for cost minimization — it batches orders for efficiency but adds 36 hours to delivery time. According to the chapter's strategic alignment principle, what is the problem?

[ ] The system is too expensive
[ ] All order-management systems should minimize cost
[ ] The retailer should change its strategy to match the system
[x] The system is not aligned with the company's strategy of fast, reliable delivery

**Explanation:** The system prioritizes cost over speed, but the company's strategy is fast delivery. This is a strategic misalignment — the system works against the strategy. Strategy should drive system design, not the reverse.
