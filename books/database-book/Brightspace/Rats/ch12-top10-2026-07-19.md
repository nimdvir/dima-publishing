## Multiple-Answer Questions

**Q1. Select ALL that apply: A dataset contains one row per student per assignment. Which calculations would correctly produce the number of students and the count of those scoring below a defined threshold?**

*Short description: Tests your ability to distinguish between record count and distinct count — a fundamental grain-awareness skill.*

A. Counting every row in the dataset to determine the number of students
B. Counting only the distinct student identifiers to determine the number of students ← ✓ CORRECT
*Feedback: Correct — when the grain is one row per student per assignment, counting distinct identifiers is the correct way to count students.*

C. Averaging all score values to identify which students are below threshold
D. Filtering to students whose average score falls below the threshold, then counting the distinct results ← ✓ CORRECT
*Feedback: Correct — this properly applies a condition at the student level before counting.*

E. Dividing the total row count by the number of assignments to estimate the student count ← ✓ CORRECT
*Feedback: Correct — although less precise than a distinct count (it assumes every student has every assignment), this is a reasonable estimation approach when the grain is known.*

**Hint:** The key concept is grain — one student appears in many rows. How do you isolate unique students?

**Explanation:** When data is stored at a finer grain than the entity you want to count, you must use distinct counting rather than row counting. Counting rows gives you the number of recorded results, not the number of students. Filtering to students meeting a condition and then counting distinct identifiers is the conceptually correct approach. Dividing total rows by assignments per student can estimate the count but is less reliable if not every student has every assignment.

**Points:** 2 | **Difficulty:** 4/5 | **ID:** BITM330-CH12-Q01 | **Bloom:** Apply

**Q2. Select ALL that apply: When using AI to assist with reporting, which practices reflect responsible use?**

*Short description: Tests your ability to evaluate AI practices against principles of source verification, human accountability, and evidentiary standards.*

A. Supplying the AI with approved, validated source documents rather than unverified data ← ✓ CORRECT
*Feedback: Correct — responsible AI use begins with verified inputs.*

B. Cross-checking every factual and numerical claim the AI produces against original sources ← ✓ CORRECT
*Feedback: Correct — AI output is not evidence by itself; every claim must be verified.*

C. Using the AI to draft an initial summary that a human then reviews and edits ← ✓ CORRECT
*Feedback: Correct — AI can accelerate drafting while humans retain editorial control.*

D. Accepting AI-generated explanations as authoritative without verification
*Feedback: Incorrect — this abdicates human responsibility for accuracy.*

E. Treating the database and validated reporting query — not the AI output — as the source of truth ← ✓ CORRECT
*Feedback: Correct — the database and reporting query remain the authoritative sources of evidence.*

**Hint:** The AI is a reporting assistant, not a replacement for verification. Which practices keep humans accountable?

**Explanation:** Responsible AI use in reporting means the AI serves as a sidecar to the reporting pipeline, not as a replacement for it. Verified source documents must be supplied as input. Every factual and numerical claim must be checked against original data. AI can draft summaries for human review and editing. The database, reporting query, and validated metrics remain the authoritative sources of truth — AI does not produce primary evidence.

## Multiple-Choice Questions

**Q3. An analyst runs a query joining student records to grade records. The query returns 400 rows, but there are only 50 students. What is the most likely explanation?**

*Short description: Tests understanding of grain — the foundational concept that one entity can appear in many analytical rows.*

A. The database is corrupted
B. The query operates at a finer grain — one row per student per graded assignment, so each student appears in multiple rows
C. The reporting tool miscounts rows by default
D. Students are double-counted because of a software bug

**Correct Answer:** B
**Explanation:** Grain determines what one row represents. When grain is one row per student per assignment, a student with 8 assignments appears in 8 rows. This is expected and correct — but row counts and entity counts are different things. The analyst must use distinct counting to identify unique students.

**Points:** 1 | **Difficulty:** 3/5 | **ID:** BITM330-CH12-Q03 | **Bloom:** Understand

**Q4. A manager wants to see how a key metric has trended month by month over the past two years. Which visual approach best serves this need?**

*Short description: Tests ability to match a business question to the appropriate chart type based on what the question asks.*

A. A pie chart showing each month's share of the total
B. A line chart with time on the horizontal axis and the metric on the vertical axis
C. A table listing every individual data point
D. A set of KPI cards, one for each month

**Correct Answer:** B
**Explanation:** Line charts are recommended for showing how a measure changes over time because position and slope communicate direction and rate of change. A pie chart shows composition, not trend. A table preserves detail but makes patterns harder to see. KPI cards draw attention to single values rather than movement across time.

**Points:** 1 | **Difficulty:** 3/5 | **ID:** BITM330-CH12-Q04 | **Bloom:** Apply

**Q5. A bar chart compares average scores across five departments. The vertical axis starts at 78 instead of zero, making an 80 and an 82 appear to be dramatically different. What principle does this violate?**

*Short description: Tests ability to diagnose dishonest visual encoding — a core data literacy skill.*

A. The chart uses too many colors
B. The visual encoding is dishonest — bar length should represent magnitude from a zero baseline
C. The chart type is wrong for comparing categories
D. The chart should have been a pie chart instead

**Correct Answer:** B
**Explanation:** Bar charts encode values through length, so the axis should begin at zero. Starting the axis at 78 exaggerates the visual difference between 80 and 82, creating a misleading impression. This is a violation of honest encoding. The chart type (bar) is appropriate for comparing categories — the problem is the axis manipulation.

**Points:** 1 | **Difficulty:** 4/5 | **ID:** BITM330-CH12-Q05 | **Bloom:** Analyze

**Q6. A saved reporting query that joins, calculates, and labels data before any visualization tool imports it acts most like which stage of data preparation?**

*Short description: Tests conceptual understanding of where a prepared query fits in the ETL/ELT spectrum.*

A. An ELT step — loading raw data first, then transforming it later
B. A small ETL layer — extracting, transforming, and structuring data before downstream use
C. A purely storage-level object with no role in the reporting pipeline
D. A complete replacement for all further data preparation

**Correct Answer:** B
**Explanation:** A reporting query that extracts data from tables, applies joins and calculations (transform), and presents a structured result for import by a visualization tool follows the ETL pattern: Extract → Transform → Load. ELT would load raw data first and transform it in the target system. The query does not replace all further preparation — additional formatting or filtering may still occur in the reporting tool.

**Points:** 1 | **Difficulty:** 4/5 | **ID:** BITM330-CH12-Q06 | **Bloom:** Analyze

**Q7. A department needs a recurring monthly summary showing exact figures by category for five senior leaders who will print and archive the document. The data lives in a single operational database. Which reporting approach is most justified?**

*Short description: Tests evaluative judgment — matching reporting tools to actual audience needs rather than defaulting to the newest technology.*

A. An interactive dashboard with animated visuals
B. A structured, printable report generated close to the source database
C. A collaborative workspace with notes and status tags
D. Both an interactive dashboard AND a printable report

**Correct Answer:** B
**Explanation:** When the audience primarily reads and prints, the format is stable, and the data is close to one operational database, a structured printable report is the best fit. Interactive dashboards add complexity without adding value for a print-and-archive workflow. Using the simplest tool that fully meets the need is better than defaulting to the most feature-rich option.

**Points:** 1 | **Difficulty:** 4/5 | **ID:** BITM330-CH12-Q07 | **Bloom:** Evaluate

**Q8. A quarterly business review uses a 3-D pie chart with fifteen segments, a bar chart with a truncated axis, and unlabeled axes throughout. What is the most fundamental problem?**

*Short description: Tests ability to identify the core failure across multiple visualization problems — loss of clarity.*

A. The presentation uses too many different chart types
B. The visuals fail the clarity test — a viewer cannot quickly and accurately understand what is being measured
C. The charts were not created with the most expensive software
D. Color choices are inconsistent across slides

**Correct Answer:** B
**Explanation:** Clarity is the most fundamental visualization principle. The viewer should quickly understand what is measured, which population is included, what the units mean, and which result matters. All the described problems — 3-D distortion, too many pie segments, truncated axis, missing labels — converge on a single failure: the viewer cannot accurately interpret the data.

**Points:** 1 | **Difficulty:** 5/5 | **ID:** BITM330-CH12-Q08 | **Bloom:** Evaluate

**Q9. A large healthcare network must compare standardized quality metrics across thirty facilities, with governed definitions, automated weekly refresh, and role-based access. Which approach is appropriate?**

*Short description: Tests ability to match organizational scale and governance requirements to the correct reporting infrastructure tier.*

A. Individual spreadsheet files emailed weekly
B. A shared collaborative workspace with manual data entry
C. A governed business intelligence platform with shared data models and scheduled refresh
D. Printed reports generated once per quarter

**Correct Answer:** C
**Explanation:** Enterprise-scale reporting with standardized metrics, automated refresh, and role-based access requires a governed BI platform. Spreadsheets lack governance and automation. Collaborative workspaces cannot enforce metric definitions or handle complex calculations at scale. Printed reports lack timeliness. The choice of reporting approach should match the organization's scale and governance needs.

**Points:** 1 | **Difficulty:** 5/5 | **ID:** BITM330-CH12-Q09 | **Bloom:** Evaluate

**Q10. A report shows a single number: "Customer Retention: 84%." Nothing else. What is the most important improvement?**

*Short description: Tests understanding that numbers gain meaning through comparison — context is essential to interpretation.*

A. Make the number larger with a more decorative font
B. Add context — such as the previous period's rate, a target range, or a benchmark
C. Convert the number into a pie chart
D. Add a second number showing total customer count

**Correct Answer:** B
**Explanation:** A number becomes meaningful through comparison. Without context — a previous period, a target, a benchmark — the reader cannot determine whether 84% is good, bad, or expected. Adding a comparison point transforms an isolated statistic into interpretable evidence. Decoration, chart conversion, or adding raw counts does not provide the missing context.

**Points:** 1 | **Difficulty:** 4/5 | **ID:** BITM330-CH12-Q10 | **Bloom:** Evaluate
